WebSocket Protocol (/ws/translate)

          

          TEXT JSON + BINARY 16KHZ INT16 PCM
        


        

          
          

            

              CLIENT → SERVER FRAMES (UPLINK ↑)
              6 FRAME TYPES
            

            

              

                

                  1. {"action": "config", ...}
                  JSON
                

                

                  Hot-update session parameters mid-stream: source_lang, target_lang, tts_enabled, engine_mode ("hybrid" | "whisper"), bidirectional, active_speaker, and auto_silence_commit.
                

              


              

                

                  2. {"action": "interim_speech", ...}
                  JSON
                

                

                  Stream cumulative speech tokens (text, is_final, segment_id). Stale partials are automatically cancelled via monotonic sequence_id; 15+ word clauses split on punctuation automatically.
                

              


              

                

                  3. Raw Binary Audio Frame
                  ARRAYBUFFER
                

                

                  16,000 Hz mono signed 16-bit little-endian PCM (Int16Array, ~2560 samples / 160 ms per frame) fed into the 240 ms pre-roll ring buffer, Silero VAD, and Faster-Whisper ASR.
                

              


              

                

                  4. "flush" / "reset" / "ping"
                  CONTROL
                

                

                  flush immediately locks any pending provisional speech/audio to final; reset clears buffers; ping returns a low-overhead pong RTT timestamp.
                

              

            

          


          
          

            

              SERVER → CLIENT EVENTS (DOWNLINK ↓)
              ASYNC PUSH
            

            

              

                

                  1. status: "partial"
                  PROVISIONAL
                

                

                  In-place while-speaking update containing utterance_id, original_text, translated_text, source_lang, target_lang, speaker, latency_ms, and audio_base64: null.
                

              


              

                

                  2. status: "final"
                  COMMITTED + MP3
                

                

                  Emitted on >800 ms VAD pause, 15-word punctuation boundary, or is_final: true. Locks the transcript row and attaches synthesized Edge Neural MP3 in audio_base64.
                

              


              

                

                  3. status: "vad" & "engine_status"
                  TELEMETRY
                

                

                  Streams live Silero VAD voice probability / RMS energy for binary PCM streams and reports non-blocking Faster-Whisper model warmup state.
                

              


              

                

                  4. "config_ack" / "pong" / "reset_ack"
                  ACK
                

                

                  Confirms applied session state immediately on handshake or mid-utterance language/mode switching.
